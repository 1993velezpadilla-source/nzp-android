# Felix / Volnox Write Access Policy

Allowed write scope when the active connector actually has write permission:
- branch: `collab/felix-volnox-sandbox`
- path: `collaborators/felix-volnox/`

Everything outside that path is read/reference-only unless the owner explicitly authorizes a specific edit.

A successful build/render/generation is not permission to promote or merge. Owner approval is always required.
