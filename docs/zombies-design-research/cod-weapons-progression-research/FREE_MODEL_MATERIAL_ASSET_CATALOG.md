## Poly Haven — CC0

https://polyhaven.com/

The official site publishes HDRIs, textures and 3D models as CC0.

Useful categories:
- barrels/crates
- industrial props
- debris
- furniture
- environment models
- HDR skies
- high-resolution PBR materials

API note: the live Poly Haven API has separate terms for API clients. Downloaded CC0 assets and API-client obligations should not be conflated.

## OpenGameArt

OpenGameArt hosts several license families.

Preferred for our commercial-safe baseline:
- CC0

Potentially usable with manifest/attribution:
- CC-BY

Do not assume every OpenGameArt item is CC0.

## Import priority

1. CC0
2. original authored assets
3. clearly commercial-compatible attribution license
4. royalty-free asset with redistribution restrictions tracked

Avoid for the original monetizable game:
- unclear license
- ripped game assets
- "free download" without rights
- NC-only content
- proprietary franchise models/audio
