## Interaction footprints

Reserve explicit clean rectangles for:
- perk machines
- wall buys
- Mystery Box locations
- Pack-a-Punch

- arsenal
- power
- traps

## Horde validation

Test these before art lock:
- one zombie
- 24+ zombie horde
- player sprinting backward
- player circling obstacle clockwise/counterclockwise
- two players crossing opposite directions
- four players around interaction
- revive under pressure
- zombie entering every ingress simultaneously
- boss/elite if applicable
- worst-case dropped items/powerups

## Readability validation

From each major doorway, ask:
- can I identify the room in <1 second?
- can I see at least one useful destination?
- is the landmark distinct?
- is the exit silhouette obvious?
- does lighting compete with the interactable?
- does clutter hide the floor route?

## Originality validation

Before public release:
- no copied original geometry
- no copyrighted ripped assets
- no copied texture set
- no copied quest sequence
- no copied exact prop composition
- no copied branded signage
- abstract pacing lessons only
