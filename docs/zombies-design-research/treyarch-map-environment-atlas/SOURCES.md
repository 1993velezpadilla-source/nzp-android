## Tool-scale reference (community, not Treyarch map geometry)

- BO3 Radiant MCP project:
  https://github.com/hetri-courses/mcp-radiant

It documents BO3-world coordinate examples as inches with Z-up and sample dimensions such as 64×96 doorway, 16 wall thickness and 512×512×256 zones. Use only to understand one mod-tool coordinate convention. It does **not** establish official dimensions of every Zombies map.

## Copyright / handling rule

Do not mirror or redistribute:
- Activision/Treyarch maps
- leaked map source
- ripped models/textures/audio
- proprietary packaged assets

Store only:
- links
- room names
- high-level topology
- design observations
- original measurements/recommendations
- original test data

If a future source is marked "not for download/distribution," the atlas may summarize publicly visible production information but must not copy the asset.
