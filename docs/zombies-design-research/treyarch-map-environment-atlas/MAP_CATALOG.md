# Map Catalog — Official Treyarch Zombies Environment Corpus

Research cutoff: **2026-09-21**.

This catalog is organized for environment/level-design study. Remasters, survival slices and large-region modes are separated so the same geometry is not counted as a completely new design.

## Modern Warfare III Zombies

### Operation Deadbolt — Urzikstan
Official MWZ was developed by Treyarch in collaboration with Sledgehammer Games and High Moon Studios. Treat Urzikstan as one large Zombies playspace rather than a conventional round-based map.

Environment lesson:
- macro POIs must be readable from vehicles
- threat zones can replace doors as progression pressure
- contracts/world events require clear staging footprints
- extraction and traversal dominate prop-scale decisions

Dark Aether rifts/story subspaces should be cataloged as **derived mission spaces**, not independent classic round-based maps.

## Remake / derivative handling rule

When an environment reuses earlier geometry:
1. compare macro topology separately from art pass,
2. note route openings/closures,
3. compare prop density and interaction placement,
4. compare lighting/landmark changes,
5. do not double-count inherited geometry as a new invention.

## Priority study set for our first original map

For a Nacht-sized first release, the highest-value references are:
- Nacht — minimal survival skeleton
- Kino — open hero space + compressed connectors
- Der Riese — compact loops + industrial shortcuts
- Nuketown Zombies — outdoor obstacle islands and two-house readability
- IX — strong central landmark/radial readability
- Dead of the Night — furniture and wall dressing as navigation
- Liberty Falls — modern small-town readability
- BO7 Survival maps — modern confined-space tuning
